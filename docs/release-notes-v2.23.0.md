# v2.23.0 Release Notes（2026-09-01）

**技能图谱：技能树之上的确定性关系图（GitNexus 启发）**

研究 GitNexus（零服务器代码知识图谱引擎）后的落地版本：宪法此前只有"树"（技能在哪个抽屉），这一版补上"关系"（技能之间怎么连）。核心借鉴是 GitNexus 的两条主张——**图谱的价值在关系确定**，以及**预计算关系智能**（关系在索引期算好，查询时零推理，不把原始图丢给 LLM 自己探索）。

---

## 一、技能图谱 `skill_graph.json`

重建技能树时自动产出（`build_skill_tree.py`），也可单跑 `scripts/build_skill_graph.py` 从现有树重建。

**三种边**（全部零依赖确定性抽取，零 LLM）：

| 边 | 含义 | 来源 |
|---|---|---|
| `chains_to` | A 的输出正好是 B 的输入（技能链衔接） | registry.json 的 input/output schema 交集——此前只有 step4 临时在用，现在固化成图 |
| `co_anchor` | 两个技能谈论同一实体（共享锚点词） | 正则抽锚点 + 两道过滤：约 200 词的套话停用词表（滤掉 creating/wants/diagnose 这类"活动词"）+ 文档频率过滤（出现在 >5% 技能里的词视为套话剔除） |
| `alternative` | 同分类、描述高度重叠，互为替代方案 | 重叠系数 ≥0.35，全局只保留最强 200 条防图爆炸 |

**聚类**：确定性标签传播（排序遍历 + 平票取字典序最小，完全可复现），技能聚成功能簇——如 code 簇（git 工作流 + 代码审查 + 增量实现）、word 簇（办公文档线）、html 簇（部署线）。

**两条纪律**（同 GitNexus 只对结构边做社区检测）：
1. 只有结构边（chains_to / co_anchor）参与聚簇——"互为替代"不代表"同一条任务线"；
2. alternative 边不做门禁放行凭证。

**明确不借**：图数据库（JSON 文件足够）、LLM 参与建边、全量 AST、每次调用重建图。

## 二、三个落地点

### 1. 注入按任务线收窄（省 token）

注入块新增「🕸️ 技能图谱」段：任务锚点技能（必需技能按 SAD 排名精选）的**同簇成员 + 一跳邻居**，每条带"为什么相关"的边证据（溯源）。注入面从"整分类清单"收窄到"这个任务真正用得上的那条技能线"。轮转填充防止某个大簇吃光整个注入预算。

### 2. 门禁 Layer F：图证据校验（step3）

任务含必需关键词（代码/部署/推送…）时，输出引用的技能必须与任务锚点**图谱连通**——同簇或结构边一跳。引用了一个真实存在但与任务锚点**图谱零连通**的技能 → FAIL，并附簇归属证据（"引用侧簇=word，锚点侧簇=code"），一眼看出为什么判负。

这是对 Layer D（描述重叠打分）的硬化：关系在索引期已经算好，校验时零推理、不可糊弄。保守面照旧：图缺失、无引用、引用不在图中（图陈旧）一律放行，不误杀。

### 3. 推荐可解释（基础已就位）

第五条推荐场景现在可以说明技能间关系（"你装了 A，B 与 A 同簇/可衔接"），图谱数据已具备，话术随场景自然使用。

## 三、质量过程（真实迭代记录）

聚类质量不是一次到位的，每一版修正都有诊断数据：

| 迭代 | 最大簇 | 修正 |
|---|---|---|
| 连通分量 + 裸锚点 | **268** | 发现套话词对（supports+search / create+asks）连出巨簇 |
| + 停用词表 v1 + 文档频率过滤 | 256 | 活动词（debugging/diagnose/fix）仍在连边 |

最终快照：457 节点 / 737 边 / 25 簇（code×21、browser×20、word×41、email×14、部署线×8…）。

## 升级方式

```bash
git pull
bash install.sh                        # 技能目录型：覆盖安装
SKILLS_DIR=<你的技能目录> python scripts/build_skill_tree.py   # 重建技能树时图谱自动产出
python scripts/tests/run_tests.py      # 应显示 99/99 通过
```

## 兼容性

- 图缺失时**所有链路行为与旧版完全一致**（注入只加段落、门禁只加一层可降级校验）——先升级后重建树也安全
- 图谱是作者快照的衍生物：仓库提交的是作者树的图谱，**你的环境重建技能树时会生成你自己的图谱**
- `SKILL_GRAPH=0` 可关闭建图（只想要树的场景）
